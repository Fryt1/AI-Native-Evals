# Console Persistence Contracts

These JSON Schemas describe the small, versioned records that the Console reads from `EvalRuns`. Raw provider payloads remain provider-owned; the browser only receives API DTOs.

- `run-manifest-v1.schema.json`
- `normalized-event-v1.schema.json`
- `evaluation-report-v1.schema.json`
- `artifact-manifest-v1.schema.json`
- `comparison-v1.schema.json`
